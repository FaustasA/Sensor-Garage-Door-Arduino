# Sensor-Garage-Door-Arduino

Arduino UNO R3 pagrindu padaryta automatinė garažo durų sistema Tinkercad.
Sensoriui aptikus automobilį Servo atidarys garažo duris, užsidegs žalia lemputė ir bus išgirstas garsinis signalas. Mašinai pasitraukus arba jai nebūnant Servo garažo duris laikys uždarytas, degs raudona lemputė ir nebus garsinio signalo.
