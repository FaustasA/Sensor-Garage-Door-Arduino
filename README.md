# Sensor-Garage-Door-Arduino

Arduino Uno R3 pagrindu padaryta automatinė garažo vartų sistema Tinkercad.<br /> <br />
Sensoriui aptikus automobilį Servo atidarys garažo vartus, užsidegs žalia lemputė ir bus išgirstas garsinis signalas. Mašinai pasitraukus arba jai nebūnant garažo vartai bus laikoma uždarytais, degs raudona lemputė ir nebus garsinio signalo.
